eu.org免费域名申请

今天就来写一下如何简单便捷的申请国际免费域名 EU.ORG 吧

首先

让我们打开注册页面：https://nic.eu.org/arf/en/login/ ，点击 Register，看下面图

点击后进入到一个页面，填写相关的信息，我们可以使用 https://www.shenfendaquan.com 此网站生成外国信息，我们将生成的信息填入相对应的地方（只需要填一下必填的项目）

请注意：邮箱一定要填自己的邮箱！！！


填完之后点击Create，成功创建完账号后，在你填写的邮箱中应该会收到EU.ORG官方发来的邮件，里面包含你的登陆账号等等一些其他的信息，请保留这封邮件；点击里面的链接激活账号，完成创建。
至此，我们便完成了第一步

其次

我们回到登陆页面
填入我们刚才获得的账号以及你设定的密码，点击Login进行登录，之后我们进入到了如下界面

接下来显而易见，让我们点击 New Domain ，进入如下界面

对于Complete domain name ，意思就是你要申请的域名是什么，例如：yvan.eu.org ;注意填写时不要过于简单，不然不通过的几率非常大
对于Organization 这一板块，在你注册时就已经填好，不需要动
对于 Administrative contact 和 Technical contact ，不需要动
这里最重要的是 Name servers 这一块。Check for correctness of 我们选 server names ，下面的域名解析，我们先填
分别填到 Name1 和 Name2 ，之后过人机验证，点击Submit，出现如下图片，即可表示成功注册

剩下慢慢等待即可，最长时间应该是30天，如果仍未通过，请更换域名重新注册

之后我会写一篇如何将注册的域名解析到免费的cloudflare中
